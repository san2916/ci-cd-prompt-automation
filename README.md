# CI/CD Prompt Automation

This project demonstrates a CI/CD pipeline using GitHub Actions.

## Features

- Automated Python testing
- Scheduled CI/CD execution
- Prompt-based automation
- Error detection
- Automated report generation
- GitHub Actions artifacts
- Agile workflow integration

## Pipeline

1. Checkout source code
2. Install Python dependencies
3. Run automated tests
4. Execute automation script
5. Generate report
6. Upload report

## Schedule

The workflow runs automatically every 6 hours.

It can also be triggered manually from GitHub Actions.
